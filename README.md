# Nekora · 快手增强模块

面向快手标准版和快手极速版的 Android 增强模块。

[下载 APK](https://github.com/DJWSJ/Nekora/releases/latest) · [更新日志](CHANGELOG.md)

## 适配范围

| 宿主 | 包名 | 适配参考版本 |
| --- | --- | --- |
| 快手极速版 | `com.kuaishou.nebula` | 14.7.20、14.7.30.11804、14.7.40.11821、14.8.20、14.8.40.11936；14.9.30.12004（播放器信息、沉浸播放与悬浮栏验证参考） |
| 快手标准版 | `com.smile.gifmaker` | 14.9.20.50799 |

以上为当前适配参考范围，不代表每个版本的全部功能均已完整实测，也不保证其间的所有小版本兼容。功能可用性还受动态插件、账号状态和设备环境影响，未列出的版本不作兼容承诺。

沉浸播放与悬浮栏的功能验证参考为标准版 14.9.20.50799 和极速版 14.9.30.12004。视频铺满只接管已核验的结构：标准版已取得合格铺底样本，极速版本轮仅核验开关联动与不支持结构的保护退让，不保证所有视频铺底。其他系统、架构及横屏未完成本轮功能验证。

### 运行要求

- 当前安装包使用 `top.djwsj.nekora`；它与旧 `top.djwsj`、`top.djwsj.nakora` 是不同应用，不能跨包名覆盖安装，旧模块 App 的数据不会自动迁移。
- 新旧包可以保留，但请在框架中只启用其中一个，避免对同一宿主重复注入。
- 安装下限为 Android 8.0（API 26）；实际可用系统版本还受宿主与框架限制。
- 正式 APK 同时提供 `arm64-v8a` 与 `armeabi-v7a`，32 位与 64 位 ARM 宿主进程都能加载模块。
- 使用支持 libxposed API 102 的框架，例如 Vector 2.2，并启用对应宿主作用域；旧 LSPosed 1.9.2 不支持此入口。
- 标准版、极速版与模块 App 的配置分别保存，开关不会自动相互同步。

## 功能

### 视频浏览与媒体保存

- 信息流视频广告过滤，自选运营弹窗拦截范围。
- 按点赞、收藏数过滤视频与图文，支持独立短剧过滤及可选兜底保留；视频筛选编辑后点击保存生效。
- 在简介下方显示发布时间、发布地和播放进度；长按加速时随宿主信息区隐藏，松手后恢复。切换作品时独立更新，数据尚未就绪时先显示占位。
- 沉浸播放：播放时收起视频之外的界面控件，暂停时显示，继续播放后约三秒自动隐藏，并提供平滑显隐过渡。
- 在分享面板查看、复制作品信息，保存视频、封面、所选图片及实况图；以宿主提供的有效资源和访问权限为前提。

### 防误触与界面个性化

- 点赞、收藏双击确认，屏蔽画面双击点赞，拦截长按点赞。
- 独立控件隐藏：按组、按项选择主页播放器控件，与沉浸播放分别设置；隐藏右侧操作项后回收空位，让剩余控件均分空间。
- 隐藏指定顶栏频道、底栏 Tab、整个底栏或拍摄加号；加号支持双击打开。
- 独立悬浮顶栏与悬浮底栏，默认关闭，使用圆角半透明样式并保留原生导航；液态玻璃为可选外观。
- “视频铺满屏幕”作为悬浮底栏的子选项，默认勾选但仅随底栏生效；底栏关闭时子项置灰并保留选择。取消子项只恢复视频布局，不关闭悬浮栏或液态玻璃，不支持的结构保持宿主原样。
- 系统手势条显示控制及边到边显示。
- 侧边栏按组、按项隐藏，支持纯色、自选图片背景与透明度调整。
- 宿主设置页换肤，模块面板支持跟随系统、浅色和深色主题。
- 宿主面板按分类进入详情，可自定义常用项的添加、移除与顺序；常用项列表按宿主分别保存，收藏入口不会自动启用功能。

### 私信与评论

- 为已捕获的对方私信保留防撤回提示，撤回文字显示在对方消息左下方，不绘制边框；支持消息推荐净化、通讯录引流内容净化和私信一键已读。
- 极速版每日定时私信：搜索昵称或 UID 并逐个勾选对象，配置正文与每日时、分；保存后需主动确认启用，按账号与对象独立去重。对象名单可能不完整或过期，发送前请核对。
- 评论背景美化、详细日期时间，以及关键词、疑似引流、长度、IP 属地等过滤。
- 本地自定义评论：仅在本机显示，不会向平台真正发布。

### 配置与排障

- 桌面主页查看已安装宿主，访问发行仓库及交流渠道。
- 宿主设置页、分享面板中的模块入口，分类设置、账号信息查看及用户 ID 复制。
- 适配缓存重建，查找进度、阶段和耗时提示。
- 查找完成后显示总耗时，由用户确认是否重启，不自动重启。
- 崩溃日志捕获与导出。
- 应用内更新下载进度、取消和手动重试，安装包校验通过后再进入系统安装确认。
- 过滤同版、低版及无效版本更新提示。

### 签到与搜索辅助

- 每日签到辅助，按宿主登录态与当前有效任务执行。
- 搜索任务辅助：浏览搜索结果时处理当前有效任务，可选择延迟执行；不自动打开搜索页面。
- 需要本地开关及相应服务权限，任务结果以宿主实际判定为准。

### 分享与服务功能

- 固定、推送作品展示与播放状态回报。
- 在服务允许的用户、好友范围内推送作品或评论，以及对应接收展示。
- 需要配套服务、正常网络及相应账号授权，不代表任意账号默认开放。
